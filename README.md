## 功能

- 文生图（`generate_image`）、改图（`edit_image`）、自拍/人像生成（`generate_selfie`）、批量生成（`generate_image_batch`）、文生视频/图生视频（`generate_video`）、任务状态查询（`get_task_status`）六个工具。
- 4 种服务商模板：标准生图接口、对话接口出图、自定义完整地址、视频接口。
- 功能链路：每个功能可以排一串服务商，前一家失败或画幅不支持时自动换下一家。
- 全局队列：并行数、排队上限、每用户图片/视频上限、批量上限都能调；失败的任务不占并行位置。
- 画廊：生成的图自动留档，收藏的不会被自动清理；图片、自拍、视频各有独立的数量与天数上限，自拍不会挤掉普通图。
- 完成通知：默认在发出图片后补一轮，把任务结果告诉模型（模板可见可编辑，留空即关闭）。
- WebUI：概览、服务商、任务、画廊、设置五个页面，全部配置都在这里改，保存后立即生效。

## 要求

- Kira `>= 3.0.2`
- Python 依赖：`aiohttp`、`httpx`、`Pillow`（见 `requirements.txt`）

## 安装

把 `kira_plugin_aiimg` 目录放入 Kira 的插件目录，重载或重启 Kira，然后在插件管理里启用。

装好后打开插件页面（侧边栏「AI 生图」），在「服务商」里添加至少一家能出图的服务商，保存即可使用。视频功能需要再添加一家视频服务商。

## 配置服务商

在「服务商 → 连接」里点「新增」，先选接口类型，再按提示填：

| 接口类型 | 适合什么情况 | 必填 |
| --- | --- | --- |
| 标准生图接口 | 最常见的对接方式，生图和改图分开调用 | 接口地址、模型名 |
| 对话接口出图 | 把提示词发给对话模型，从回复里取图（Gemini 系和各类网关常用） | 接口地址、模型名 |
| 自定义完整地址 | 接口路径不标准，生图、改图各有一个完整网址 | 生图地址 |
| 视频接口 | 提交任务后按固定间隔查询结果 | 服务地址、模型名 |

常用字段说明：

- 接口地址：填到 `/v1` 这一层就行，后面的生图、改图路径会自动接上。
- 密钥：一行一个；填多个时轮流用，某个用失败会换下一个。
- 默认画幅：写 `1024x1024`、`3:4 4K`、`2K` 这类都可以，留空按 `1024x1024`。
- 可选画幅：一行一个。只有服务商挑尺寸时才填，留空表示不限制。
- 比例对照：键是比例、值是画幅，用来指定某个比例优先用哪个尺寸，一般不用填。
- 额外请求参数：以 JSON 形式随请求发送，服务商有特殊参数时才需要。
- 代理地址、超时秒数、重试次数、图片格式：按需调整，默认值适用大多数情况。

每家服务商保存时都会校验，缺必填项或格式不对会直接提示。

## 功能链路

「服务商 → 功能链路」里，每个功能一行一家服务商，从上到下尝试：

- 文生图、改图、自拍、批量生图、视频各自独立。
- 右侧画幅可以留空，留空就用功能默认值。
- 服务商不支持改图、或者画幅不被接受时，会自动跳到下一家。
- 没有排顺序时，用第一个能用的服务商。

## 工具与队列

| 工具 | 说明 |
| --- | --- |
| `generate_image` | 文生图，参数 `prompt`、`provider`、`size`/`aspect_ratio`/`resolution`（画幅也可以直接写在提示词末尾，如 `1024x1024`、`3:4 4K`、`2K`） |
| `edit_image` | 改图，使用当前消息或回复消息中的图片 |
| `generate_selfie` | 自拍/人像生成，基于「设置 → 自拍参考图路径」里的参考照片 |
| `generate_image_batch` | 批量生成，参数 `prompts`（数组，上限 `batch_max_count`） |
| `generate_video` | 文生视频或图生视频；带图时用当前或回复消息里的图片 |
| `get_task_status` | 查询任务状态 |

队列参数在「设置 → 队列」：并行数（默认 2）、排队上限（默认 16）、批量上限（默认 8）、批量并行（默认 2）、每人图片任务上限 / 视频任务上限（默认各 1）、记录保留小时数（默认 24）。

## 提示词策略

不内置任何隐藏提示词。所有层均可配置：

- 服务商的 `prompt_template`（比如自拍可见模板 `selfie_prompt_template`、视频底图模板 `selfie_video_frame_template`）支持 `{{prompt}}` 占位符；留空表示不追加。
- 每个任务都保存 `prompt_layers` 与 `final_prompt` 审计字段，方便回看最终提示词。
- 完成通知模板 `terminal_notification_prompt` 同样可见可编辑，留空关闭。

## WebUI

插件页面提供五个页面：

- 概览：服务商数量、队列情况、画廊统计、最近任务。
- 服务商：「连接」里增删改服务商，「功能链路」里排顺序。
- 任务：运行中、排队中和最近记录，可以取消还没跑完的任务。
- 画廊：按时间倒序，可以按类型筛选、收藏、删除、点开看大图。
- 设置：权限、默认画幅、队列、画廊保留、框架接管。

改动会在右上角提示「有未保存的修改」，点「保存配置」后立即生效；还有任务在跑时会先问一句，确认后才会应用。页面默认浅色，右下角可以切深色，选择会记住。

## 数据存储

数据目录为 Kira 的 `data/plugin_data/kira_plugin_aiimg/`：

- `gallery/`：成功图片文件；`gallery.sqlite3`：画廊索引
- `tasks.sqlite3`：任务记录
- `agnes_video/requests.sqlite3`：视频限速账本

## 访问控制

在「设置 → 访问控制 → 白名单」里填名单，一行一个，用户编号和群编号都认：

- 只写编号：这个用户或这个群可以用。
- 写「平台名:编号」：限定平台，比如 `qq:123456`。
- 群编号写进来后，这个群里所有人都能用。

留空表示不做限制，谁都能用。名单外的人调用工具时会收到「无权使用该功能」，任务状态也只能查自己的。

## 和框架自带生图的关系

本插件定位是取代框架自带的生图。插件运行期间，框架自带的出图写法（`<img>`、`<selfie>`、`<video>` 三个标签）会被摘掉，出图只走本插件的工具，避免同一句话出两次图；其它插件自己注册的同名标签不受影响，比如 NAI 的 `<img>` 照常工作。

只有能接得住的时候才会接管：一个生图服务商都没配时，框架自带那套保持可用；`<selfie>` 还要求先填好自拍参考图，`<video>` 要求配了视频服务商。「设置 → 框架接管」会写明当前是否已接管。

装了本插件不用再去框架设置里关「图片生成」，那个开关留着就行；本插件卸载或停用后自带那套会自己回来。

需要两套并存时，把「设置 → 框架接管 → 取代框架自带的出图标签」关掉（默认开）。关掉后框架自带那套会重新出现。
